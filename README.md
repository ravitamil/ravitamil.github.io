## Domain options

- The free account website is `ravitamil.github.io`. Its account name comes from the GitHub username.
- You can add project paths such as `/quality-lab/` without buying a domain.
- For a name such as `ravikumartamilmani.com`, first register a domain, then configure it in this repository's **Settings → Pages → Custom domain** and add the DNS records GitHub specifies. Verify domain ownership and enable HTTPS after provisioning.
- Update canonical URL, Open Graph URL, sitemap, robots sitemap reference and external profile links when the preferred domain changes.
- Avoid changing your GitHub username simply to rename this website: it affects account and repository URLs.

Official instructions: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) · [Custom domains](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site).
